# Portfolio maintenance

This repository is the standalone public-facing portfolio source for Victor Woelffel.

- Keep personal facts grounded in content.js and docs/CONTENT_SOURCES.md. Do not invent dates, results, project ownership or skill levels.
- Update French and English together. OptiFrame is a team hackathon project; EEG results are contextual experimental results; C proficiency must not be overstated.
- Treat all diagrams as original conceptual illustrations, not measured data or actual project screenshots.
- Keep this a static, accessible, responsive site. Prefer the existing dependency-free HTML/CSS/JavaScript architecture.
- Edit source files at the repository root. dist/ is generated by npm run build.
- Before delivery, run npm run check, npm test and npm run build. Inspect affected interactions and layouts in the browser when available.
- Keep private application databases, inbox exports, offers and credentials outside this repository.
- The bundled PDF files are copies of existing validated CVs. Do not describe them as newly generated generic CVs. Regenerating CVs requires the original personal database, LaTeX template and validation workflow.
- Respect the user's requested publication scope. Routine content edits and review-branch pushes do not imply a production deployment. The existing workflow automatically publishes pushes to codex/public-portfolio; only push that branch when publication is authorized.

## Public Git history

- The public branch is codex/public-portfolio. Its first commit contains an audited snapshot of authorised files.
- codex/portfolio keeps earlier local work history that includes withdrawn material. Never push that historical branch, --all, or --mirror. Push only the public branch and its future descendants.
